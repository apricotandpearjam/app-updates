# Kontakt Artwork

## 1.1.4, 11 November 2026
- Restoring a backup is safer: your current artwork is only swapped out once the copy has finished, so a restore that stops halfway can no longer leave you with less.
- Revert now asks before it puts the original artwork back.
- If some artwork can't be written in a batch, the list stays open and shows which ones, so nothing fails quietly.
- The Backup tab now tells you when the backup in your folder came from another Mac.
- Kontakt's own settings file is never overwritten if it can't be read.
- Image search skips very large pictures, so one bad result can't slow the app.
- Your licence is now kept in the Keychain and re-checked about once a month.

## 1.1.3, 5 November 2026
- If your backup folder moves or goes missing, Kontakt Artwork now tells you plainly and lets you choose the new location. It never quietly makes a new folder.
- If a library's drive isn't plugged in, you get a short card: "Your artwork still works. Plug it in when you can." It closes by itself when the drive comes back.
- Backups now also run once a day when you open the app, so a quiet month no longer leaves your backup weeks old.
- Backups follow the Kontakt Artwork folder when iCloud Drive moves it.

## 1.1.2, 27 October 2026
- Get help now sends your message straight to us from inside the app, with an optional name and a short report attached so we can see what went wrong. Or send it from your own email app if you prefer.
- If Kontakt Artwork ever closes unexpectedly, it offers to send a report the next time you open it.
- Privacy Policy link in Help, and clearer help links in light and dark mode.

## 1.1.1, 4 October 2026
- Backups to iCloud Drive no longer make numbered copies of your libraries ("8DIO 2", "8DIO 3"). Any copies already there are cleared the first time you open this version.
- Libraries that share a name in Kontakt now each get their own row, so both can have artwork.

## 1.1 — 25 September 2026
- Auto generate builds real compositions: the cover multiplied or mirrored across the banner, the name in its own light or on a backdrop.
- Repeat: mirror or multiply any picture to any side, flip, gap, empty middle, or a reflection at the far edge of the frame.
- Text and Subject tools: drag a box, and the lettering or subject is lifted onto its own layer or removed.
- Type: system font families, weights, letter spacing and line spacing.
- Backdrops and vignettes that know where the words are; the vignette spares the layer it sits under.
- Pictures: soften edges, turn sideways or upside down, keep only the subject.
- Grounds: any colour or gradient in any direction, with paper, linen or brushed texture, grain and fade.
- Eyedropper for every colour. Centre snapping while dragging, right-angle snapping and a degrees readout while turning.
- One INSTALL writes tile and banner together, with a preview of the band Kontakt always shows.
- Sidebar in Kontakt's own order, drag to change it; Art only rows; hide expansions.
- Build from the classic Libraries view. Deactivate this Mac. Crash report attached to Get help.

## 1.0 — 21 September 2026
First release.

- Give any Kontakt library a proper 420x316 tile and 1280x212 banner
- Covers found for you, drag one in and install
- Layer editor: type, borrowed logos, backdrops, sticky notes, box-remove, isolate text
- Reorder the Default view by hand or by manufacturer, save arrangements as scenes
- Back up artwork, shipped originals, order and scenes to iCloud, Dropbox or any folder
- Originals archived before anything is replaced, one button puts them back
